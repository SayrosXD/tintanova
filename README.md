# TintaNova

Sitio del prototipo de tinta vegetal de Ingeniería Agroindustrial de la Universidad Nacional Francisco Luis Espinoza Pineda. Incluye un lienzo digital, una mesa para comparar pigmentos, un diagrama interactivo de las diez etapas y una ficha técnica con un simulador de balance de materia.

## Ejecutar

Abre `index.html` en un navegador o sirve el directorio con un servidor estático. Puedes usar `python -m http.server 8000` y entrar en [localhost:8000](http://localhost:8000/). El sitio no requiere compilación, cuentas ni dependencias externas de ejecución.

## Publicación

[TintaNova en Render](https://tinta-nova.onrender.com/) se despliega desde la rama `main`. El comando `npm run build` prepara el directorio `dist` con los archivos públicos.

## Material visual

El logotipo, la propuesta del envase y el diagrama de proceso provienen del informe académico. Las fotos de extracción y filtración documentan la prueba con remolacha. La portada es una ilustración generada para el sitio a partir de una composición editorial con una pincelada ámbar, un frasco gotero, zanahoria, remolacha y espinaca sobre papel de acuarela. Las licencias de las tipografías están en `assets/`.
