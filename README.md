# TintaNova

Sitio del prototipo de tinta vegetal de Ingeniería Agroindustrial de la Universidad Nacional Francisco Luis Espinoza Pineda. Presenta tres pigmentos, un lienzo para probar su paleta y una ficha técnica con un simulador de balance de materia.

## Ejecutar

Abre `index.html` en un navegador o sirve el directorio con un servidor estático. Puedes usar `python -m http.server 8000` y entrar en [localhost:8000](http://localhost:8000/). El sitio no requiere compilación, cuentas ni dependencias externas de ejecución.

GitHub Pages sirve los archivos desde la raíz de la rama `main`.

## Material visual

El logotipo, la propuesta del envase y el diagrama de proceso provienen del informe académico. La portada es una ilustración generada para el sitio a partir de una composición editorial con una pincelada ámbar, un frasco gotero, zanahoria, remolacha y espinaca sobre papel de acuarela. Las licencias de las tipografías están en `assets/`.
